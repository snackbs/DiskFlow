应用图标交付 —— 生产级可编辑 SVG + 多尺寸 ICO/PNG

白色盘片 = 磁盘本体 青色数据流 = 读写流水 左箭头写入 / 右箭头读出 蓝渐变方底 = Windows 11 图标规范

概念：一枚白色磁盘被两道青色数据流穿过 —— 左箭头流入（写入）、右箭头流出（读取）， 直观表达 DiskFlow「磁盘累计读写量与增量监测」的核心功能；主轴孔镂空透出底色，与背景浑然一体。

绘制基准与安全区

  • · 画布 256×256，圆角 rx=58（约 22.7%，对齐 Windows 11 应用图标规范）
  • · 内容（磁盘 + 数据流）居中，四周留白 ≥ 10%（约 26px），任何尺寸下不得裁切圆角
  • · 磁盘 r=52、数据流高 18、磁道弧 r=33，关键结构落在 8px 网格上（弧线端点为视觉微调）
  • · SVG 不写死 width/height，由使用方（CSS / 组件 / 转换工具）控制尺寸

命名约定

  • · 文件：kebab-case，diskflow-{用途}[-{底稿}].svg
  • · SVG id：统一 df- 前缀；分组 df-background / df-flow / df-disk
  • · 渐变 df-bg / df-gloss / df-stream，滤镜 df-shadow
  • · 图层顺序：背景 → 数据流 → 磁盘（改色时按组整组替换，不要单点改）

集成方式

  • · PyInstaller：--icon diskflow.ico（或重命名为 app.ico 后加进 build.bat）
  • · README：![DiskFlow](png/diskflow-256.png)（GitHub 不渲染 SVG，故用 PNG）
  • · GUI：标题栏 / 关于框可用 diskflow-mark-24.svg 或对应 PNG

Do / Don't

  • ✓ 按尺寸档位选用对应文件
  • ✓ 换品牌色时整组同色系替换（背景/数据流一起改）
  • ✓ 24 标用 currentColor 适配深浅主题
  • ✓ ICO 内含 16–256 全尺寸，可直接用于 --icon
  • ✗ 非等比拉伸 / 压缩
  • ✗ 在盘片上叠加文字或徽标
  • ✗ 转换格式时丢失 viewBox
  • ✗ 用于 DiskFlow 以外的产品
